# Marquee

One ad server and console for every app at [mutaafaziz.com](https://mutaafaziz.com). Google AdSense banners,
H5 Games Ads interstitial and rewarded video, and direct sponsors (image and video). It has kid-safe defaults
and aggregate-only counting. Everything is driven from `/ads/admin`, or by an agent over the [agent API](docs/AGENT_API.md).

See [AGENTS.md](AGENTS.md) for the policy, how to integrate an app, and how to run it.
